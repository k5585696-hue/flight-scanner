🔑 設定 GitHub 金鑰（每台裝置設定一次）

網頁要改你 GitHub 專案裡的航線設定，需要一把「只能改這個專案」的金鑰。金鑰只存在這台裝置的瀏覽器，不會給別人。

  1. 打開 GitHub 建立金鑰頁面 ↗（要先登入 GitHub）
  2. Token name 隨便取，例如「機票雷達」；Expiration 選最長的期限
  3. Repository access 選 Only select repositories，再選 flight-scanner
  4. Permissions 加入 Contents，權限選 Read and write
  5. 按最下面 Generate token，複製 github_pat_ 開頭的那串字，貼到下面
